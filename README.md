# Mini Shell Project

This project is a small interactive shell written in C for Linux.

## Build

```sh
make
```

The executable is named `mysh`.

```sh
./mysh
```

Run `make clean` to remove object files and the executable.

## Implemented shell features

- `exit` exits the shell. An optional numeric status is accepted.
- A final `&` starts a command or pipeline in the background.
- `Ctrl-C` interrupts the foreground process group while leaving the shell
  available for another command.
- `Ctrl-Z` stops the foreground process group. `jobs`, `fg`, and `bg` provide
  a small job-control interface.
- `<`, `>`, and `>>` redirect standard input and output.
- `|` connects commands in a pipeline.
- Single and double quotes, backslash escapes, `$NAME`, `${NAME}`, and `~` at
  the start of a word are recognized by the parser.
- The required file commands are implemented in this project: `ls`, `pwd`,
  `cd`, `mkdir`, `rmdir`, `ln`, `cp`, `rm`, `mv`, `cat`, and `grep`.
- Other command names are passed to `execvp` so common Linux utilities can
  still be used from the shell.

## Command option scope

These implementations support a practical subset of the common options:

- `ls`: `-a`, `-l`, `-R`
- `mkdir`: `-p`
- `rmdir`: `-p`
- `ln`: `-s`, `-f`
- `cp`: `-r`, `-R`
- `rm`: `-r`, `-R`, `-f`
- `cat`: `-n`
- `grep`: `-i`, `-v`, `-n`, `-c`, `-l`, `-E`

This is a course project shell, not a replacement for Bash or another
production shell. Features such as command substitution, wildcard expansion,
here-documents, and complete GNU option compatibility are outside this
implementation's scope.

## Signal note

On a typical Linux terminal, `Ctrl-Z` generates `SIGTSTP`; `SIGQUIT` is
normally generated by `Ctrl-\\`. This implementation follows the terminal's
usual key mapping. The project handout labels `Ctrl-Z` as `SIGQUIT`, so the
expected interpretation should be confirmed with the course instructor and
described accurately in the final report.
